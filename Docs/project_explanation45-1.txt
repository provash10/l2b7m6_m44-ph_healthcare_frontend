================================================================================
          PH Healthcare Frontend - প্রজেক্ট ও ফাইলগুলোর বিস্তারিত গাইডলাইন
================================================================================

এই ডকুমেন্টটিতে এখন পর্যন্ত প্রজেক্টে যে যে ফাইল তৈরি বা ব্যবহার করা হয়েছে, 
কোন ফাইলটি কী কাজ করছে এবং পুরো আর্কিটেকচার কীভাবে একসাথে কাজ করছে তা 
ধাপে ধাপে বাংলায় বিস্তারিত ব্যাখ্যা করা হলো।

--------------------------------------------------------------------------------
১. প্রজেক্টের প্রযুক্তি ও আর্কিটেকচার (Technology Stack)
--------------------------------------------------------------------------------
- Framework: Next.js (App Router, version 16+)
- Runtime & Package Manager: Bun
- State & Data Fetching: @tanstack/react-query
- Form Management: @tanstack/react-form
- Schema Validation: Zod
- Styling: Tailwind CSS (v4)
- UI Library: Shadcn UI + Base-UI
- Icons: Lucide-React
- HTTP Client: Ofetch

--------------------------------------------------------------------------------
২. ধাপে ধাপে প্রতিটি ফাইলের কাজ ও ব্যাখ্যা (Step-by-Step File Details)
--------------------------------------------------------------------------------

১. Providers লেয়ার (Global State ও Context):
--------------------------------------------------
ক) src/providers/query.provider.tsx:
   - কাজ: TanStack React Query সেটআপ করা।
   - কেন প্রয়োজন: সার্ভার কম্পোনেন্ট এবং ক্লায়েন্ট কম্পোনেন্টের মধ্যে যাতে 
     ক্যাশ (cache) ঠিকমতো হ্যান্ডেল হয় এবং প্রতি রেন্ডারে নতুন ক্লায়েন্ট 
     তৈরি না হয়, তার জন্য `makeQueryClient()` এবং `getQueryClient()` ফাংশন 
     ব্যবহার করা হয়েছে।
   - `QueryProviders`: পুরো অ্যাপ্লিকেশনের চারপশে `<QueryClientProvider>` 
     র‍্যাপ করে যাতে যেকোনো কম্পোনেন্ট থেকে API ক্যাশিং ও ফেচিং করা যায়।

খ) src/providers/index.tsx:
   - কাজ: সেন্ট্রাল প্রোভাইডার ব্যারেল (Hub)।
   - ভবিষ্যতে যত প্রোভাইডার আসবে (যেমন: Auth, Theme, Google Provider ইত্যাদি), 
     সেগুলো এই ফাইলে একসাথে সাজানো হবে এবং মূল লেআউটে পাঠানো হবে।


২. মূল রুট লেআউট (Root Layout):
--------------------------------------------------
ক) src/app/layout.tsx:
   - কাজ: পুরো অ্যাপ্লিকেশনের প্রধান HTML কাঠামো (`<html>` এবং `<body>`)।
   - ফন্ট লোডিং: Google Fonts (Geist, Geist Mono, Inter) ভ্যারিয়েবল আকারে লোড 
     করা হয়েছে।
   - গ্লোবাল স্টাইল: `globals.css` ইম্পোর্ট করা।
   - বডিতে `<QueryProviders>` দিয়ে রুট চিলড্রেনকে র‍্যাপ করা হয়েছে যাতে পুরো অ্যাপ 
     কোর স্টেট এক্সেস পায়।


৩. রাউটিং ও পেজ লেআউট (App Router Routing):
--------------------------------------------------
ক) src/app/(public)/(marketing)/layout.tsx:
   - কাজ: পাবলিক ওয়েবসাইট (Home, About Us ইত্যাদি) এর লেআউট।
   - এতে উপরে `<Header />` এবং নিচে `<Footer />` যুক্ত থাকে এবং মাঝে পেজের কন্টেন্ট থাকে।

খ) src/app/(public)/(authentication)/login/page.tsx:
   - কাজ: লগইন পেজের মূল ভিউ।
   - ডিজাইন: এটি একটি আধুনিক ২-কলাম গ্রিড লেআউট:
     - বাম পাশে: ব্র্যান্ড লোগো/নাম এবং মাঝখানে `<LoginForm />` কম্পোনেন্ট।
     - ডান পাশে: একটি রেসপনসিভ ব্যানার ইমেজ (`/login.jpg`), যা বড় স্ক্রিনে শো করে 
       এবং ছোট স্ক্রিনে নিজে থেকেই হাইড হয়ে যায়।


৪. হেডার ও নেভিগেশন (Header & Navigation):
--------------------------------------------------
ক) src/components/layout/public/Header.tsx:
   - কাজ: ওয়েবসাইটের টপ নেভিগেশন বার।
   - রুট লিস্ট: `routes = [{ name: "Home", url: "/" }, ...]` ম্যাপ করে লিঙ্ক তৈরি করা।
   - ব্র্যান্ডিং: বাম পাশে লোগো (`<Logo />`) এবং নাম (`PH Healthcare`) পাশাপাশি সাজানো।
   - বাটন: ডান পাশে শ্যাডসিএন বাটনের ভেতর Next.js Link ব্যবহার করে Login পেজের 
     বাটন যুক্ত করা।
   - [নোট]: এই ফাইলেই `Logo` ডুপ্লিকেট ইম্পোর্ট হয়েছিল, যা পরে ফিক্স করা হয়েছে।


৫. অ্যাসেটস ও ভেক্টর লোগো (Assets & SVG):
--------------------------------------------------
ক) public/logo.svg:
   - কাজ: মূল লোগোর র (raw) ভেক্টর ফাইল।

খ) src/assets/svg/logo.tsx:
   - কাজ: সাধারণ SVG কোডকে একটি পুনঃব্যবহারযোগ্য (Reusable) React কম্পোনেন্টে রূপান্তর করা।
   - সুবিধা: `<Logo />` কম্পোনেন্ট হিসেবে ব্যবহার করায় আপনি বাইরে থেকে `className`, 
     `width`, `height`, `style` ইত্যাদি props পাস করতে পারবেন।
   - কোডের খুঁটিনাটি:
     - `import type { SVGProps } from "react"`: টাইপ সেফটি নিশ্চিত করে।
     - `{...props}`: প্যারেন্ট থেকে পাঠানো যেকোনো ক্লাস বা স্টাইল এসভিজিতে অ্যাপ্লাই করে।
     - `stopColor`: React JSX-এ `stop-color` এর জায়গায় ক্যামেলকেস ব্যবহার করা হয়েছে।


৬. লগইন ফর্ম ও লজিক (Form & State Management):
--------------------------------------------------
ক) src/components/form/login-form.tsx:
   - কাজ: ইউজার লগইন করার ফর্ম এবং ইনপুট ফিল্ড হ্যান্ডেল করা।
   - ফর্ম ম্যানেজমেন্ট (@tanstack/react-form):
     - `useForm()` হুকের মাধ্যমে `email` ও `password` এর রিয়েলটাইম স্টেট ট্র্যাক করে।
     - `validators: { onSubmit: LoginSchema }`: ফর্ম সাবমিটের সময় Zod স্কিমা দিয়ে 
       তথ্য যাচাই করে।
   - পাসওয়ার্ড শো/হাইড ফিচার:
     - `const [showPassword, setShowPassword] = useState(false);`
     - ইনপুটের টাইপ ডাইনামিক: `type={showPassword ? "text" : "password"}`
     - ইনপুটের ডানপাশে অ্যাবসোলিউট পজিশনে বাটন:
       `<button onClick={() => setShowPassword((prev) => !prev)}>`
     - আইকন টগল: `showPassword ? <EyeClosed /> : <Eye />`
   - এরর স্টেট:
     - `field.state.meta.isTouched && !field.state.meta.isValid` দিয়ে চেক করে 
       ইনপুটে এরর থাকলে লাল বর্ডার ও এরর মেসেজ `<FieldError />` দেখানো হয়।


৭. ভ্যালিডেশন স্কিমা (Data Validation):
--------------------------------------------------
ক) src/validation/auth.validation.ts:
   - কাজ: ইউজারের ইনপুট করা ডাটা সঠিক কি না তা Zod লাইব্রেরি দিয়ে ভ্যালিডেট করা।
   - নিয়মনীতি:
     - `email`: অবশ্যই সঠিক ইমেইল ফরম্যাট হতে হবে (`z.string().email()`)।
     - `password`:
       * সর্বনিম্ন ৮ অক্ষরের হতে হবে (`.min(8)`).
       * অন্তত ১টি ছোট হাতের অক্ষর থাকতে হবে (`/[a-z]/`).
       * অন্তত ১টি বড় হাতের অক্ষর থাকতে হবে (`/[A-Z]/`).
       * অন্তত ১টি সংখ্যা থাকতে হবে (`/[0-9]/`).
       * অন্তত ১টি বিশেষ চিহ্ন (@, #, $, ইত্যাদি) থাকতে হবে (`/[^A-Za-z0-9]/`).

খ) src/validation/index.ts:
   - কাজ: সমস্ত ভ্যালিডেশন ফাইলগুলোকে একসাথে বাইরে এক্সপোর্ট করার ব্যারেল ফাইল।


৮. UI কম্পোনেন্টস (Shadcn UI Base Components):
--------------------------------------------------
- src/components/ui/button.tsx: ভ্যারিয়েন্ট ও সাইজ সহ স্ট্যান্ডার্ড বাটন।
- src/components/ui/input.tsx: স্টাইলিশ ইনপুট ফিল্ড (ফোকাস রিং, এরর স্টেট সহ)।
- src/components/ui/field.tsx: ফর্ম ফিল্ড, লেবেল, হেল্পার টেক্সট ও এরর মেসেজ দেখানোর 
  কম্পোনেন্ট সেট।
- src/components/ui/label.tsx: অ্যাক্সেসিবল টেক্সট লেবেল।

--------------------------------------------------------------------------------
৩. পুরো সিস্টেমের ডেটা ফ্লো (How Everything Works Together)
--------------------------------------------------------------------------------
১. ইউজার ব্রাউজারে `/login` রাউটে প্রবেশ করে।
২. Next.js `src/app/(public)/(authentication)/login/page.tsx` রেন্ডার করে।
৩. সেখানে `<LoginForm />` লোড হয়।
৪. ইউজার ইমেইল ও পাসওয়ার্ড লেখার সাথে সাথে TanStack Form স্টেট ট্র্যাক করে।
৫. ইউজার চোখের আইকন (`<Eye />` / `<EyeClosed />`) এ ক্লিক করলে `showPassword` স্টেট 
   পরিবর্তন হয়ে পাসওয়ার্ড দৃশ্যমান বা অদৃশ্য হয়।
৬. সাবমিট বাটনে ক্লিক করলে TanStack Form স্বয়ংক্রিয়ভাবে `LoginSchema` রান করায়।
৭. যদি পাসওয়ার্ড বা ইমেইল ভুল ফরম্যাটে থাকে, সাথে সাথে নিচে লাল রঙে সতর্কবার্তা ভেসে ওঠে।
৮. সব ভ্যালিডেশন পাস হলে `onSubmit` হ্যান্ডলারে কনসোলে ক্লিন ডাটা প্রিন্ট হয় (ভবিষ্যতে API কল যাবে)।
